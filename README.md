### 🚀 Key Projects & Implementations

#### 1. [Touchless Virtual Keyboard System](https://github.com/Nijo-Idicula-Jacob/Virtual-keyboard-)
*Real-time gesture-driven interface eliminating the need for physical input peripherals.*
- Implemented hand-landmark tracking and continuous spatial coordinate mapping using OpenCV.
- Developed sub-second debounce logic and key-stroke triggering based on Euclidean distance thresholds.
- **Technologies:** `Python` &bull; `OpenCV` &bull; `Computer Vision` &bull; `HCI`

#### 2. [Integrated ML Web Inference Engine](https://github.com/Nijo-Idicula-Jacob/Flaskapp_with_ML)
*A complete end-to-end predictive web service connecting trained algorithms to end users.*
- Built a responsive web portal backed by a Flask routing layer consuming pre-trained scikit-learn models.
- Handled input serialization, validation, and real-time inference latency optimization.
- **Technologies:** `Flask` &bull; `scikit-learn` &bull; `Python` &bull; `HTML/CSS`

#### 3. [Automated Facial Recognition & Attendance System](https://github.com/Nijo-Idicula-Jacob/faculty-recoginition-programme)
*Biometric computer vision pipeline engineered for faculty identification and presence logging.*
- Engineered feature extraction and face encoding algorithms to match video frames against registered identity matrices.
- Structured an automated logging pipeline to export attendance records directly into structured data formats.
- **Technologies:** `OpenCV` &bull; `Python` &bull; `Biometrics` &bull; `Data Automation`

#### 4. [Personal Portfolio & Technical Showcase](https://github.com/Nijo-Idicula-Jacob/nijo-idicula-jacob.io)
*Responsive, single-page application demonstrating engineering builds and background.*
- Optimized for performance and cross-device compatibility with zero bloated dependencies.
- **Technologies:** `HTML5` &bull; `CSS3` &bull; `JavaScript` &bull; `GitHub Pages`
